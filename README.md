# ☕ Afficionado Coffee Roasters – Sales Analysis Dashboard

## 📌 Project Overview

This project presents an interactive sales analysis dashboard for **Afficionado Coffee Roasters**.

The objective of this project is to analyze coffee sales data and identify important patterns related to **sales performance, store performance, product performance, revenue, quantity sold, and peak sales hours**.

An interactive dashboard was developed using **Python and Streamlit** to make the analysis easy to explore and understand.

---

## 🎯 Project Objectives

- Analyze overall coffee sales performance
- Identify the best-performing coffee products
- Compare sales performance across different stores
- Analyze sales by transaction hour
- Identify peak sales hours
- Analyze revenue and quantity sold
- Provide interactive filters for better analysis
- Build a live and interactive web dashboard

## 📂 Dataset

The project uses the **Afficionado Coffee Roasters** sales dataset provided in Excel format.

The dataset contains transaction-level coffee sales information that can be used to analyze:

- Transaction details
- Product information
- Store performance
- Transaction time
- Sales quantity
- Revenue
- Coffee product categories

The dataset was prepared before building the dashboard.

The main data preparation steps included:

- Checking for missing values

- Checking column data types

- Creating calculated sales/revenue metrics

## 📊 Dashboard Features

The Streamlit dashboard provides an interactive view of coffee sales performance.

### Key Performance Indicators

The dashboard includes important KPIs such as:

- Total Revenue
- Total Quantity Sold
- Total Transactions
- Average Sales
- Store Performance

### Sales Analysis

The dashboard analyzes:

- Sales trends
- Revenue performance
- Quantity sold
- Product performance
- Store performance
- Hourly sales performance

### Time-Based Analysis

Transaction time is analyzed to identify:

- Peak sales hours
- Low-performing hours
- Hourly transaction patterns

### Product Analysis

The dashboard helps identify:

- Best-selling products
- Highest revenue-generating products
- Product-wise quantity sold
- Product performance comparison

---

## 📈 Key Business Insights

The dashboard can help management answer questions such as:

1. Which coffee products generate the highest sales?
2. Which store performs the best?
3. What are the peak sales hours?
4. Which products have the highest quantity sold?
5. How does sales performance change throughout the day?
6. Which products or stores require further attention?

These insights can support better decisions related to **inventory planning, staffing, promotions, and sales strategy**.
